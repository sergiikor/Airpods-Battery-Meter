# Анимации форка

Покадровые PNG (в GNOME Shell нет WebGL) + mp4-превью для просмотра.
Исходники сцен: `/home/sergii/rust_projects/hello_world/airpods_anim/`
(`index.html` — intro/попап, `index_connect.html` — connect/меню,
`airpods_4.glb` — модель).

## intro/ — hero попапа подключения
- `frames/` — 105 кадров 680×440 @15fps (~7с), однократно.
- Сюжет: кейс открывается, бады вылетают и разъезжаются в стороны
  ровно над кольцами L/R (cx 114/341/569), низы в линию с кейсом.
- `preview.mp4` — то же для быстрого просмотра.
- Использование: `lib/modern/airpodsPopup.js` (`playOnce`).

## connect/ — hero меню панели
- `frames/` — 76 кадров 400×508 @15fps (~5с), бесшовный цикл:
  отрезок t=4.0–9.0 (idle 1.0–6.0, ровно один период sway 2π/5).
- Сюжет: бады парят над открытым кейсом, встречное покачивание.
- `preview.mp4` — то же для быстрого просмотра.
- Использование: `PopupMenuWidgetBox` (`playLoop` при открытии,
  `stop` при закрытии).

## idle/ — запас под боковую шторку
- 118 кадров 680×216 @15fps, бесшовный цикл вращения.
- Пока не используется (roadmap: Screen 1 side sheet).
